## 后续整理

每次完成工作后，检查新增发布包、构建临时目录、实验日志与预览。
被当前版本替代的文件移入备份根目录的新时间戳批次，记录来源相对路径、用途和 SHA-256；
不覆盖旧批次。`LATEST.txt` 指向最近批次，根目录 README 保留历次入口。
构建钩子仍先写入 `backups/firmware/`，整理时再迁入外部备份；全部历史版本继续保留。

恢复单个文件时，先在清单中核对摘要，再复制所需文件到新位置；目标已有文件时先另存，
不要整目录覆盖当前工作区。旧固件恢复仍须核对设备、分区、OTA、应用摘要和恢复路径。
备份中的构建副本含指向当前工具链的 junction，不作为独立开发环境使用。

本机备份链接随项目目录一起移动时，应同步移动旁边的 `XTE-Link-备份/`。
其他克隆不包含这些本机历史文件，当前构建和运行不依赖它们。

推送前文档格式与索引快照保存在 [2026-10-19_193550](../../XTE-Link-备份/2026-10-19_193550/README.md)；
