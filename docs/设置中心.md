# 当前设置中心

适用于 `maintenance-20261019`。设置功能沿用六分类界面，复用 SDK 显示、输入与 SD 接口；
当前软件验证和设备待验项见[维护性修复验证](维护性修复验证-2026-10-19.md)。

| 分类 | 设置项与行为 |
| --- | --- |
| 显示与刷新 | 更新间隔 5/10/30 秒；清残影关闭/每 20/50/100 次快刷；立即全刷 |
| 屏保图库 | 随机/固定一张/顺序；选择、预览并确认固定 |
| 启动与操作 | 菜单/指定应用/上次应用；默认应用包含 Clash；音量步长 1/5/10 |
| 连接与配对 | USB/局域网；供电、驱动、SSID、WiFi、IP、RSSI、协议诊断；重新连接 |
| 助手提醒 | 关闭/仅角标/切到助手；数量提示及延迟跳页 |
| 设备与电源 | 版本、TF、MiSans、heap、参考电压；电池闲置休眠关闭/5/15/30 分钟；恢复默认 |

默认菜单启动、状态应用、5 秒更新、音量步长 5、随机屏保、仅角标；自动清残影和自动休眠关闭。
电池继续使用 SDK 默认分压系数，未重新校准；GPIO20 只表示接电，不区分是否充满。

## 横屏操作

右侧 ↑↓ 选择，✓ 打开，顶部 ←→ 编辑候选值，✓ 保存，× 取消或返回。
分类返回应用菜单，子列表返回分类，详情返回子列表；诊断与信息页用 ✓ 重新采样。
图库用 ↑↓ 选图、✓ 预览；预览用 ←→ 换图、✓ 固定、× 返回图库。
SDK 键名与横屏方向的转换见[按键方向约定](按键方向约定.md)。

## 图库、启动与提醒

图库包含 `/.sleep/` 与根目录 `/sleep.bmp`，最多 200 项，目录文件名最长 63 字节。
只读取 800×480、未压缩的 1/4/8 位调色板 BMP，不在设备端缩放。
随机避开上一张，顺序按路径循环；预览不推进轮换记录。文件缺失或读取失败时，休眠回退内置像素画。
从旧设置迁移时，已有根目录屏保先沿用为固定图片；仅用户确认改变后保存。

默认应用决定菜单选中项或指定应用启动；“上次应用”只记录该模式下的手动切换。
Clash 直启进入首页，驱动上线后重发只读列表请求；唤醒重新取得实时数据，不恢复旧审批缓存。
审批自动跳页等待按键松开至少 800 ms，设置页、TF 传输、Clash 等待及确认期间不抢页面。
请求过期或已处理时取消排队；跳页不会批准或拒绝请求。

## 休眠与持久化

自动休眠仅在电池供电时生效；按键、USB 接电、TF 传输、待审批、设置页与 Clash 等待/确认暂停计时。
深睡停止接收消息，长按电源唤醒，未增加定时唤醒。

Preferences 使用 Arduino-ESP32 自带版本。`xte-link/settings2` 的 89 字节 blob 同时保存偏好与固定图片路径；
写入成功才更新运行时设置，未改值不写 NVS。旧 `settings`、连接 `lan`、`lastApp` 和 `sleepLast` 保留兼容用途。
恢复默认需确认，先保存默认偏好再切换 USB；保留 TF 图片、字库、WiFi、配对与其他命名空间。
两步提交不宣称跨键原子性，不修改引导器、分区、OTA 或恢复槽。

主机回归可运行 `firmware/tests/verify_settings.py`，前置依赖见[开发环境](开发环境.md)。
历史实现与刷入记录见[归档说明](归档说明.md)；软件结果不能替代实屏、NVS 掉电或深睡唤醒验收。
