# 横屏方向与固件键名约定

记录日期：2026-10-13。适用于初代 Xteink X4 在本项目当前横屏摆放下的界面。
物理位置依据用户描述；图标和操作方向是本项目的界面约定。

这里有两个方向参照：SDK/固件保留原有 `UP/DOWN/LEFT/RIGHT` 键名，
用户看到的提示与操作采用横屏视角。同名的“上、下、左、右”不能直接混用。

| 横屏物理位置 | 原固件定义 | SDK 常量 | 横屏图标 / 方向 |
| --- | --- | --- | --- |
| 顶部最左侧 | 电源 | `BTN_POWER` | 不绘制常用键提示 |
| 顶部中间 | 上 | `BTN_UP` | ← 左 |
| 顶部最右侧 | 下 | `BTN_DOWN` | → 右 |
| 右侧从上到下第 1 键 | 右 | `BTN_RIGHT` | ↑ 上 |
| 右侧从上到下第 2 键 | 左 | `BTN_LEFT` | ↓ 下 |
| 右侧从上到下第 3 键 | 确认 | `BTN_CONFIRM` | ✓ 确认 |
| 右侧从上到下第 4 键 | 返回 | `BTN_BACK` | × 返回 / 取消 |

**需求、界面文案与操作说明采用横屏方向；代码、串口调试和 SDK API 引用采用原键名。**
例如，“横屏上键选择上一项”应检查 `InputManager::BTN_RIGHT`；
“横屏左键调整到前一个值”应检查 `InputManager::BTN_UP`。
不要根据图标方向重新定义 SDK 按键、修改 ADC 解码或引脚；转换发生在页面事件处理与绘图处。
更改设备摆放或屏幕旋转时，应重新核对这张映射表。

## 当前主菜单操作

| 横屏操作 | 行为 | 对应 SDK 按键 |
| --- | --- | --- |
| 顶部 ←/→ | 循环切换前一页 / 后一页 | `BTN_UP` / `BTN_DOWN` |
| 右侧 ↑/↓ | 当前页上一项 / 下一项，按左上、右上、左下、右下循环 | `BTN_RIGHT` / `BTN_LEFT` |
| ✓ | 打开选中应用；未实现的占位项不执行动作 | `BTN_CONFIRM` |
| × | 保持主菜单 | `BTN_BACK` |

两页分别保留选中项；开机和唤醒按设置选择菜单、指定应用或上次应用，Clash 对应第二页。
第二页包含快捷功能（闪电）、Clash Verge（网络节点）、占位二（便签）、占位三（加号）。
Clash Verge 是主菜单独立应用入口，支持列表及二次确认操作。

## 当前设置页操作

当前设置从分类首页进入，↑↓ 选择分类，✓ 进入、× 返回。
图库 ↑↓ 选图，✓ 预览；预览 ←→ 换图、✓ 固定、× 返回图库。
列表与编辑操作见[设置中心](设置中心.md)和 [README 横屏操作](../README.md#横屏操作)。

| 设置状态 | 横屏操作 | 对应 SDK 按键 |
| --- | --- | --- |
| 列表 | 右侧 ↑/↓ 选择上一项 / 下一项 | `BTN_RIGHT` / `BTN_LEFT` |
| 编辑 | 顶部 ←/→ 切到前一个 / 后一个候选值 | `BTN_UP` / `BTN_DOWN` |
| 打开 / 保存 | ✓ | `BTN_CONFIRM` |
| 取消 / 返回 | × | `BTN_BACK` |

列表状态的顶部方向键、编辑状态的右侧方向键不执行操作，避免误切页或误改值。
主菜单和设置页使用上述横屏映射，其他功能页的按键分配保持原有实现。
因此读其他页面代码时，仍应将 SDK 键名先转换为横屏方向，再理解它执行的功能。

实现位于 `firmware/src/main.cpp` 的 `renderButtonHints()`、`handleSettingsButtons()`
与 `handlePageButtons()`；主机检查在 `firmware/tests/settings_test.cpp` 中用
`SCREEN_UP/DOWN/LEFT/RIGHT` 表达横屏方向，并明确映射到 SDK 常量。

当前页面行为见 [README](../README.md)，实现与主机检查随源码保留。
设备实际版本应以发布 manifest 和最新刷入记录为准。
