# 当前 TF 字库与 Legacy20 兼容

当前 `maintenance-20261019` 沿用 MiSans 4.009 Medium 的四个固定字号。
旧 Zheng 字库与 Legacy20 读取器保留供兼容和回退；实际页面显式选择 MiSans。
当前交付的刷入状态见[项目 README](../README.md#固件与验证)。

来源、许可、生成命令、文件摘要见 [tools/misans](../tools/misans/README.md)。
字库不随公开仓库分发；固件只引用 TF 文件路径。

## 页面接入

- 24px：连接状态、页脚提示、设置行、图库列表和 Clash 行；35px 行高可放入现有 42px 行。
- 32px：正文、状态标签、一般页面标题与休眠文字；46px 行高，现有行间距足够。
- 40px：菜单标题和音量标题；57px 行高，菜单保持原 132px 卡片与选择框。
- 64px：音量数值；仅加载数字和所需标点，保留原进度条。

ASCII 设备名、时间、指标值与电脑请求正文继续使用原 GFX 字体。
没有新增字号设置，没有改动按键、协议、引脚、分区、OTA 或恢复流程。
系统信息字库行及启动日志明确注明使用 MiSans。

## 读取器

`TfFont::Face` 仅含 Legacy20 与四个固定 MiSans 字号，仍只有一个读取器、一个字体文件和
8 个字形缓存。`beginRender(face)` 开始一帧，`select(face)` 切换字号时关闭原文件、清缓存，
检查新文件头和区间表；字形记录/位图继续按需 seek/read。`endRender()` 在刷新前关闭文件。
SDK 的 SD 与 EPD 仍在主循环中串行使用共享 SPI，不加载整套中文字库或完整字形表。

区间容量从 128 提至 256，单字缓存仍为 512 B；新字库实测上限 325 B。
ESP32-C3 ELF 中读取器为 **7412 B**（旧版 5868 B，增加 1544 B），仍受 8192 B 静态断言限制。
该值不包括 SDK 的 SD 缓冲、文件动态分配或调用栈，运行时 heap 仍需真机测量。
一帧中任何打开/读取/格式错误都会关闭文件，余下文字显示相应尺寸方框；下一帧重新尝试。
缺单字仅画方框；不循环重试，也不静默换用其他字体。

默认 `beginRender()` 保留 Legacy20，供旧字库校验和回退使用；实际页面显式选择 MiSans。
文件路径为 `/fonts/MiSans-Medium-{24,32,40,64}.epdfont`，不要重命名或覆盖
`/fonts/Zheng20号.epdfont`。更换字号属于页面绘制选择，不重定义 SDK 方向名。
